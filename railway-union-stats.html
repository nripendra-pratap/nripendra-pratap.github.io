    Under the hood How this page stays current

    The whole page is driven by one small file, assets/cricket-stats.js. It holds a SEASONS array with one entry per summer, and everything above (career totals, averages, economy, strike rates, career-best score and figures) is derived from it at render time. There is no second copy of the totals to forget to update.

    So the update ritual after a season, or a good week, is:

    // assets/cricket-stats.js

const SEASONS = [
  {
    year: 2026, matches: 18,
    bat:   { inns: 18, no: 4, runs: 372, sr: "121.56", hs: "68*", hsVs: "Ashbourne 2",
             fours: 31, sixes: 20, fifties: 1, hundreds: 0, ducks: 2 },
    bowl:  { ballsBowled: 390, maidens: 3, conceded: 387, wickets: 15,
             best: "4-45", bestVs: "DLR County 2" },
    field: { ctKeeper: 0, ctField: 4, stumpings: 0, runOuts: 2 }
  },
  // ...older seasons below
];
    1. Open the CricketStatz profile and pick the season from the Seas filter.
    2. Copy the batting and bowling summary rows into that season's object.
    3. Update CAREER_SR with the all-time strike rate (the one figure that cannot be recomputed, since balls faced are not published per season).
    4. Bump UPDATED, add anything memorable to HIGHLIGHTS, and push.

    A new season is a new object at the top of the array. Nothing else on the page needs touching.

    Adding a photo to the hero

    The rolling backdrop is driven by a PHOTOS array in the same file. To add one, drop three files into assets/cricket/ — <slug>-1000.webp, <slug>-1800.webp and a <slug>-1400.jpg fallback, all cropped to 16:9 — then add a single line: 

    const PHOTOS = [
  { slug: "bowling", focus: "50% 26%", alt: "A bowler in his delivery stride." },
  // ...add here
];

    focus is the CSS object-position, i.e. which part of the frame to keep when it is cropped to the hero. Nudge the second value down towards 20% when a subject's head sits high in the frame. The carousel, the dots and the paging all size themselves to however many photos are in the array.
